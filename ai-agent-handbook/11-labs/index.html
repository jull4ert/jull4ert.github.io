動手練習

在一個 ASP.NET Core MVC＋Vue 的小專案上，用 9 個練習把手冊的技巧實際做一遍。

只讀不練是學不會的。這一區提供一個練習專案與 9 個循序漸進的練習，每個都有目標、步驟、提示、預期結果與參考解答。

本章範例以 ASP.NET Core MVC（.NET 8）＋ Vue 3，前後端在同一個 .NET 專案為基準。若你的專案是 .NET Framework 的 ASP.NET MVC 5，觀念與流程相同，但建置與測試指令（例如 MSBuild、vstest）、專案檔格式與設定檔不同，請在你的 CLAUDE.md 中寫清楚。
專案內刻意有缺陷與缺漏（有 bug、缺功能、有不安全的寫法），這是練習素材，不是範本。請不要把它的寫法帶回正式專案。

練習清單

每個練習的做法

  1. 先讀目標與步驟，但不要先看參考解答。
  2. 開新分支：git switch -c lab2-fix。
  3. 自己和 agent 一起做，需要時查提示。
  4. 對照「預期結果」與「檢核」，確認真的做到。
  5. 最後才看參考解答，比較你和它的差異，並寫學習紀錄。
參考解答只是「一種可行的做法」。你的 agent 產出的程式碼可能不同，只要符合驗收條件且測試通過，就是正確。重點是過程：你有沒有驗證、有沒有看懂。

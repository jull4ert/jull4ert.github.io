Lab 0：環境與試跑

把練習專案複製出來、編譯、跑測試、啟動網站，並第一次在專案裡啟動 agent。

預計時間：30～45 分鐘　前置：.NET 8 SDK、Node.js、git、Claude Code 已安裝

目標

  • 把 OrderDemo 複製到你自己的資料夾，並建立獨立的 git 儲存庫。
  • 確認建置與測試都能執行。
  • 啟動網站看到訂單列表。
  • 在專案資料夾啟動 agent，做三個唯讀問答。

步驟

1. 複製專案並建立 git

:: 把 sample/OrderDemo 整個資料夾複製到你的工作目錄，例如 D:/work/OrderDemo
cd D:/work/OrderDemo
git init
git add -A
git commit -m "初始狀態"

一定要複製出來並建立自己的 git，不要直接在手冊倉庫裡練習，避免弄亂手冊。

2. 建置與測試

dotnet test
node --test

專案內附 nuget.config，只使用 nuget.org，避免公司內部的私有套件來源要求登入而造成還原失敗。

3. 啟動網站

dotnet run --project src/OrderDemo.Web

看輸出中的網址（例如 http://localhost:5000），開啟 /Orders 頁面，應看到部門 1 的訂單表格。

4. 啟動 agent 並做唯讀問答

claude
> 這個專案是什麼？用 5 句話說明架構。
> 測試怎麼跑？目前有哪些測試？
> 前端是怎麼呼叫後端的？

請在專案根目錄啟動，並先不要讓它修改任何檔案。

預期結果

指令預期
dotnet test已通過！失敗 0、通過 6、總計 6
node --testpass 3、fail 0
瀏覽器 /Orders顯示 6 筆訂單（部門 1），日期欄為 YYYY-MM-DD
agent 問答能指出 MVC、API、Service、記憶體 Repository、Vue 的角色

檢核

  • 我有自己的 git 儲存庫，且初始 commit 已建立。
  • 測試結果與預期相同。
  • 我看到網頁，並試著切換「狀態」篩選。
  • agent 的回答中，我能找到一個和程式碼對得上的地方，並說出是哪個檔案。
常見問題
  • NuGet 還原失敗（NU1301）：檢查是否有全域或公司的套件來源需要驗證；專案的 nuget.config 已清除其他來源，確認它在專案根目錄。
  • 找不到 .NET 8：執行 dotnet --list-sdks，需包含 8.x，或安裝 .NET 8 SDK。
  • 頁面空白：Vue 以 CDN 載入，需要能連到 unpkg.com；檢查網路與瀏覽器主控台。
  • 連接埠被占用：加上 --urls http://localhost:5187。

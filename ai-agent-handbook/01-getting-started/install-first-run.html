安裝與第一次啟動

選介面、登入、在專案資料夾啟動。

介面選擇

介面適合特色
終端機 CLI多數情境、腳本與自動化功能最完整，可搭配 CI、排程
IDE 擴充（VS Code、JetBrains）邊寫邊問、看內嵌 diff能引用目前選取的程式碼與開啟的檔案
桌面版 / 網頁版不想碰終端機、長時間背景任務介面友善，部分進階設定較少

第一次啟動

cd 你的專案
claude
  • 啟動位置就是 agent 的「工作目錄」，它預設只在此範圍內讀寫。請務必在專案根目錄啟動，不要在家目錄或磁碟根目錄。
  • 第一次會要求登入；之後在對話中可用 /help 查看指令。
  • 新專案建議先執行 /init，讓它掃描專案產生初版 CLAUDE.md（再手動精簡，見 02）。

建議的前置條件

  • 專案已在 git 下，且啟動前工作區乾淨，方便比對與退回。
  • 能用一行指令跑建置與測試（agent 需要自行驗證）。
  • 機密不放在專案明文檔案裡（見 09 治理）。
指令名稱、快捷鍵與檔案位置會隨版本調整，以官方文件與你機器上 /help 的顯示為準。

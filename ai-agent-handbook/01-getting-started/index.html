入門：以 Claude Code 為例

用具體工具把 Lv0 的觀念落地：從安裝到做出第一個可驗收的小修改。

本區以 Claude Code（終端機中的 agent）為例。觀念同樣適用其他 agent，只是指令名稱不同。

初階工程師請先看新手專區：先補齊 git、測試與讀 diff 的基本功，再做 Lab 0。

建議順序

十分鐘上手流程

  1. 在專案資料夾啟動 claude。
  2. 先問：「這個專案在做什麼？入口在哪？怎麼跑測試？」，用唯讀問答熟悉專案。
  3. 切到計畫模式，描述一個小修改，看它的計畫。
  4. 核准後讓它改，檢視 diff，執行測試。
  5. 滿意就 commit；不滿意就退回重來。
指令名稱、快捷鍵與檔案位置會隨版本調整，以官方文件與你機器上 /help 的顯示為準。

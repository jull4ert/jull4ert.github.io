AI Agent 開發手冊

學會用 AI agent 把事做得更好更強：從需求到程式碼由 agent 代勞，並讓 agent 交叉審查找出盲點，再延伸到行事曆、Trello 等工作流程。

新手從這裡開始

新手專區：四週學習路徑 已完成

如果你是剛開始的工程師，不要從頭讀到尾。照四週路徑：每週有目標、要讀的頁面、要做的練習和檢核點。

  • 前置知識補課（git、讀 diff、xUnit、HTTP 與 Vue 基本概念）
  • 動手練習：在 ASP.NET Core MVC＋Vue 的練習專案上做 9 個練習
  • 驗證看不懂的程式、把 agent 當老師、過度信任的警訊
  • 能力檢核：判斷自己是否已能獨立協作

定位與範圍

  • 定位：不只是入門，更是「怎麼用得更好、更強」的技巧庫。初學者可由 Lv0 起讀，熟手可直接跳到文件、工具箱、交叉審查。
  • 目標：你負責說清楚要什麼與做決定；釐清需求、寫規格、寫碼、測試、審查由 agent 代勞，並且讓 agent 互相挑戰，找出你和單一 agent 都看不到的盲點。
  • 範圍內：軟體開發全流程，以及非程式工作流程（行事曆、Trello、Slack、Gmail、Notion 等協作工具整合）。
  • 示範工具：以 Claude Code 為主，觀念可套用到其他 agent。
  • 範圍外：模型訓練原理、從零自建 agent 框架。

三條主軸

① 餵對文件

agent 的表現取決於它讀到什麼。學會寫它讀得懂、用得上的文件。

② 交叉審查

用獨立情境、不同角色、對抗式提問，抓出需求與程式碼的盲點。

③ 串成工作流

把重複流程變成 skill、hook、排程，並接上行事曆與 Trello 等工具。

省 Token 速查

省 Token 的技巧不集中在一頁，而是分散在各主題中，隨流程出現。以下是各頁「省 Token 技巧」段落的索引。

  • 情境視窗與分段交付　Token 花在哪、如何量測
  • 模式與常用指令　/clear、/compact、/context、/model
  • 寫出好指令　指令具體化、限制輸出
  • 讀懂專案與小修改　限定探索範圍、探索結果存檔
  • CLAUDE.md：專案常駐規範　常駐文件的固定成本
  • SKILL.md：按需載入的專業流程　漸進式揭露
  • 規格、ADR 與術語表　可分段讀取的文件
  • 給 Agent 的寫作原則　省字的寫法
  • ① 需求訪談　訪談階段
  • ③ 設計與任務拆解　subagent 探索、計畫檔接力
  • ④ 實作　一任務一對話、過濾輸出
  • ⑤ 驗證　分層驗證、輸出摘要化
  • ⑥ 交付　交付階段
  • 程式碼審查　控制審查成本
  • 整合與裁決　收斂規則即預算
  • 需求審查　需求審查的低成本做法
  • Skills 與 Plugins　每個 skill 的常駐描述成本
  • Subagent：獨立情境的專職助手　隔離即省、用較小模型
  • MCP：連接外部系統　工具定義佔情境、查詢要有範圍
  • Hooks：保證會發生的自動化　取代「請記得」的提示
  • 推薦組合與常見坑　盤點常駐成本、停用不用的
  • 平行與多 agent 分工　平行省時間不省錢、先小樣本
  • Headless 與 CI 整合　只傳 diff、限制輪數
  • 排程與定時工作　先用腳本判斷有沒有事
  • 整合行事曆、Trello 與協作工具　查詢範圍、只取需要欄位
  • 非程式工作流程食譜　篇幅限制、提案與建立分開
  • 設計與維護自己的工作流程　確定性步驟搬進腳本
  • 資料與機密　縮小資料範圍、deny 大型無關檔案
  • 權限與防護　白名單、hook 事前攔截
  • 成本控管　省 Token 技巧總索引與優先序
  • 品質評估　評測集小而精、量測自動化
  • 團隊導入與規範　共用規範與用量儀表板
  • 範例 A：一句話需求到交叉審查　階段清空、審查依風險
  • 範例 B：既有專案加功能並補測試　探索結果存檔
  • 範例 C：把每週手動流程改成自動化　限定查詢範圍、頻率適中
  • 食譜總覽　一個食譜一個對話、只貼例外附近的 log
  • 食譜：讀懂舊的 MVC 專案　導覽存成筆記
  • 一頁速查表　省 Token 速記、plugin details 看成本

基礎觀念

Lv0：開始動手前，先建立共同語言。約 20 分鐘讀完。

這一區不教操作，只建立四個觀念。後面所有章節（寫程式或處理行事曆、Trello）都建立在這四點上。

如果你是初階工程師，建議先看新手專區的四週學習路徑，再回來讀這一區。

一句話版本

Agent = 模型 + 工具 + 迴圈。它不只回答，而是「想 → 呼叫工具（讀檔、跑指令、查行事曆）→ 看結果 → 再想」，直到任務完成或需要你決定。你的角色從「自己動手」變成「定目標、給限制、做核准、驗收」。

本區頁面

讀完你應該能回答

  • 我該把任務描述到多細，agent 才不會亂猜？
  • 為什麼長對話後 agent 會「忘記」前面的事？
  • 哪些動作我必須親自核准？
  • agent 的輸出，我該檢查哪裡？

工具就是能力邊界

Agent 能做什麼，完全取決於給它哪些工具。

工具類型程式工作非程式工作
檔案讀寫原始碼整理文件、報表
指令列建置、測試、git批次處理檔案、呼叫腳本
搜尋/網頁查文件、API 用法查資料、比較方案
MCP 連接器資料庫、Issue 系統行事曆、Trello、Slack、Gmail、Notion

MCP（Model Context Protocol）是把外部服務接給 agent 的標準方式，進階區會專章說明如何整合行事曆與 Trello。

你的新角色

  • 定目標：要什麼結果，不是怎麼做。
  • 給限制：不能動什麼、用什麼風格。
  • 做核准：有副作用的動作由你放行。
  • 驗收：用可檢查的方式確認結果。

進階工作流程

把 agent 從「對話助手」升級成「可重複、可排程、可串接工具的工作流程」。

前面各區讓你學會和 agent 一起把一件事做好。這一區處理另一個問題：重複發生的事、需要多個 agent 分工的事、要跟外部工具互動的事（行事曆、Trello、Slack、信件）。

從對話到工作流程

對話式 你問一句、它做一句 （Lv1～4） │ 可重複 把流程寫進 skill，一句話觸發 （03） │ 可自動 hook / 排程 / CI 在事件或時間到時執行 （本區） │ 可分工 多個 subagent 平行、互相審查 （本區 + 05） │ 可串接 MCP 連到行事曆、Trello、Slack、信件 （本區）

頁面

設計工作流程的五條原則

原則說明
確定性的交給程式，判斷交給 agent格式轉換、排序、呼叫 API 用腳本；摘要、分類、起草用 agent
先唯讀，再寫入先讓它只產生「建議清單」，信任後才開放建立、修改
寫入前有人工關卡對外可見、難以還原的動作，由你核准
狀態存在檔案，不在記憶裡中間結果、已處理清單寫成檔案，可接力、可檢查
可重跑（冪等）重複執行不會產生重複卡片、重複信件
旗標、指令與設定欄位會隨版本調整，請以官方文件與 claude --help 的實際輸出為準；範例腳本請先在安全的環境小規模測試。

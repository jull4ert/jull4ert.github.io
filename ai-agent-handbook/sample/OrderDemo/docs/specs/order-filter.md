# 訂單列表：日期區間篩選（練習用規格草稿）

## 目標
客服人員可在訂單列表依「建立日期」區間篩選，並可與既有的「狀態」篩選同時使用。

## 非目標
- 不做出貨日期篩選
- 不改權限模型（沿用部門過濾）
- 不做匯出

## 驗收條件
1. 只選起日：回傳建立日期 >= 起日（當日 00:00 起）的訂單。
2. 只選迄日：回傳建立日期 <= 迄日（當日 23:59:59 止）的訂單。
3. 同時選起訖日：回傳區間內（含頭尾兩天）的訂單。
4. 與狀態篩選同時使用時，兩個條件皆須成立（AND）。
5. 起日晚於迄日：API 回傳 400，訊息為「起日不得晚於迄日」。
6. 沒有符合的資料：前端顯示「查無資料」，並保留已選條件。

Agent 愛讀的文件

agent 的表現取決於它讀到什麼。這一區教你寫它讀得懂、用得上的文件。

Agent 讀文件的方式

文件何時被讀放什麼
CLAUDE.md每次對話開頭自動載入專案常駐規範、指令、禁忌
SKILL.md只有描述常駐；任務相關時才載入全文可重複的流程與專業做法
規格、ADR、術語表需要時由 CLAUDE.md 或指令引導去讀需求細節、決策脈絡、領域用語
README、程式註解探索專案時讀給人也給 agent 的入口

核心取捨：常駐的越多越貴、越容易被稀釋。常駐只放「每次都要」的；其餘用「需要時才載入」的方式。

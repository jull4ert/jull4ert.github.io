AGENTS.md 與跨工具共用

同一份規範，讓不同的 agent 工具都讀得到。

AGENTS.md 是什麼

AGENTS.md 是社群推動的跨工具慣例檔名，許多 coding agent 會讀它。Claude Code 以 CLAUDE.md 為主要檔案；若團隊同時用多種工具，避免維護兩份重複內容。

做法

做法說明
以 AGENTS.md 為主檔CLAUDE.md 只寫一行 @AGENTS.md 匯入，再補充 Claude 專屬設定
以 CLAUDE.md 為主檔只用 Claude Code 的團隊，最簡單
符號連結可行，但 Windows 與部分 git 設定較麻煩
# CLAUDE.md
@AGENTS.md
## Claude Code 專屬
- 大型重構先進計畫模式
各工具對檔名與巢狀載入的支援不同，採用前請以該工具文件確認。

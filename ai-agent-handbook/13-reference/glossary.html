術語表

AI agent 與 .NET／前端相關的常見詞彙。

AI agent 相關

詞意思
Agent能使用工具（讀檔、跑指令、呼叫外部服務）並自己迴圈執行的 AI；不只是一問一答
Token模型處理文字的計量單位，影響費用與情境上限
情境（context）／情境視窗agent 目前「看得到」的內容總和：指令、歷史、讀過的檔案、工具輸出；有上限
計畫模式只讀不改，先提出計畫等你核准
權限／核准agent 要執行有副作用的動作時，需要你同意
CLAUDE.md每次對話自動載入的專案規範文件
Skill（SKILL.md）按需載入的流程與知識；平時只常駐名稱與描述
Subagent擁有獨立情境的專職助手，做完只回報結論
MCPModel Context Protocol，把外部服務接給 agent 的標準介面
Hook在特定事件由系統強制執行的指令，不靠 agent 記得
Plugin把 skill、agent、hook、MCP 設定打包的可安裝單位
Headless／非互動以 claude -p 在腳本與 CI 中執行，不開對話畫面
Prompt injection外部內容夾帶指示，誘導 agent 做壞事；外部內容是資料，不是指令
Worktree同一個 git 儲存庫的多個獨立工作目錄，讓多個 agent 平行作業
同源偏誤同一個 agent 自己審自己，會一起複製盲點
交叉審查換情境、角色、資訊或模型，讓審查者獨立找問題

開發流程相關

詞意思
驗收條件可以直接寫成測試的「完成」標準，常用 Given / When / Then
垂直切片每個任務貫穿必要的層，做完就有一小段完整行為
TDD測試驅動開發：先寫失敗的測試，再寫程式讓它通過，再整理
特徵測試記錄既有行為的測試（不論對錯），用來在重構或修改前鎖住現況
臨時破壞手動改壞一行程式，確認測試會失敗，藉此驗證測試有效
ADR架構決策紀錄：為什麼選 A 不選 B
事前驗屍假設已經失敗，倒推原因，找出需求與設計的缺漏
證據表「驗收條件｜驗證方式｜證據｜結果」的對照表
diff變更前後的差異

.NET 與前端相關

詞意思
MVCModel-View-Controller：Controller 接請求、Model 表示資料、View 產生畫面
Razor.cshtml 中混合 HTML 與 C# 的樣板語法，@ 是 C# 的起點
Service／Repository商業邏輯層／資料存取層
DI（依賴注入）由框架提供物件給需要它的類別，註冊時要注意生命週期（Singleton／Scoped／Transient）
DTO用於傳輸的資料物件，避免直接暴露內部實體
xUnit.NET 常用的單元測試框架（[Fact]、[Theory]）
EF Core／migration物件關聯對應工具／資料庫結構變更的版本紀錄
N+1 查詢迴圈中每筆資料各查一次資料庫，造成大量查詢
CSRF／防偽造權杖防止其他網站假冒使用者送出請求的機制
XSS把惡意腳本注入頁面執行的攻擊
Vue 響應式資料改變時，畫面自動更新的機制
v-model／v-for／v-onVue 的雙向綁定、迴圈、事件指令
Vite前端建置工具；用在較複雜的 Vue 專案

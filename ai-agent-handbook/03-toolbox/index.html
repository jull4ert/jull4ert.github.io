工具箱：外掛與擴充

Claude Code 的五種擴充方式，以及什麼情況該用哪一種。

Agent 的能力來自「情境 + 工具」。這一區介紹你能加到它身上的五種東西，以及最重要的：怎麼選。

五種擴充一覽

擴充它是什麼何時載入典型用途
CLAUDE.md常駐規範文件每次對話專案慣例、指令、禁忌（見 02）
Skill按需載入的流程與知識相關時才載入全文commit 格式、審查清單、報表流程
Subagent獨立情境的專職助手被呼叫時啟動探索、審查、平行作業、隔離大量輸出
MCP連接外部系統的標準介面連線期間工具定義常駐資料庫、Issue、行事曆、Trello、Slack
Hook在特定事件自動執行的指令事件發生時由系統觸發自動格式化、攔截危險操作、通知
Plugin把以上打包、可安裝與分享安裝後啟用團隊共用一整套設定

怎麼選：一張決策表

你想要…用
每次都要遵守的規則CLAUDE.md
某類任務的標準做法，不想常駐佔位Skill
大量搜尋、審查、不想汙染主對話Subagent
讓 agent 讀寫外部服務MCP
「一定要發生」的自動動作（不能靠 agent 記得）Hook
把以上整包給團隊或自己跨專案使用Plugin

關鍵區別：CLAUDE.md、skill 是「建議」，agent 可能沒做；hook 是「保證」，由系統強制執行。必須 100% 發生的事（格式化、阻擋危險指令），請用 hook。

子頁面

設定檔位置、欄位名稱與指令選項會隨版本調整，請以官方文件與你機器上的 /help、/agents、/mcp、/plugin 實際畫面為準。

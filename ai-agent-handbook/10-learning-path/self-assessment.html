能力檢核：你到哪一級了？

用具體可驗證的項目，判斷自己是否已能獨立和 AI 協作。

每一級都列出「做得到」的證據。建議每項都留下可以拿出來的東西：PR、證據表、規格檔，而不只是自我感覺。

第 1 級：會用（第 1 週後）

  • 能在專案根目錄啟動 agent，並用唯讀問答了解專案。
  • 能用 @、!、計畫模式、/clear。
  • 能看 git diff，並還原不要的修改。
  • 能用自己的話說明一個請求從前端到資料的路徑。
  • 證據：Lab 0、Lab 1 完成；有一份自己整理的架構筆記。

第 2 級：會驗證（第 2 週後）

  • 能先寫失敗的測試，再修正，並說明為什麼。
  • 能用五步驗證法確認 agent 的修改。
  • 能辨認常見的程式碼警訊。
  • 知道什麼情況要找同事。
  • 證據：Lab 2、Lab 3 完成；PR 說明含驗證紀錄。

第 3 級：能協作（第 4 週後）——目標

  • 能帶著 agent 走完：訪談、規格、拆解、實作、驗證、交付。
  • 規格有可驗收的條件，並做過需求審查。
  • 每個驗收條件都有證據，證據表中誠實標出「不通過」。
  • 做過交叉審查，並能對發現做出採納或駁回的決定與理由。
  • 能把專案慣例寫成 CLAUDE.md 與至少一個 skill。
  • 知道哪些事不能交給 agent。
  • 證據：Lab 4～8 完成；一個含規格、計畫、證據表、審查裁決表的小需求。

第 4 級：能帶人（之後）

  • 能為團隊設計共用的 CLAUDE.md、skills、審查流程。
  • 能評估 agent 的產出品質並持續改進。
  • 能把例行工作做成排程或工作流程，並設定安全邊界。
  • 能指導別人，並處理 agent 出錯的事故。
  • 證據：共用規範被團隊採用；有指標追蹤品質與成本。

如何自評

狀況建議
某一級有 2 項以上做不到回頭重做對應的 Lab，不急著升級
全部做得到，但總是靠 agent 解釋多用「先寫後審」的方式練習
全部做得到，且能教別人往下一級，並開始做 06 進階工作流程

請同事幫你驗收

找一位資深同事看你的 Lab 8 成果，請他回答三個問題：

  1. 如果這是我團隊的 PR，我會放心合併嗎？
  2. 哪一個決定最讓我擔心？
  3. 這個人知道自己不知道什麼嗎？

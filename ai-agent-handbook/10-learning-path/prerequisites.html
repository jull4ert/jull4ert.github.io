前置知識補課

用 agent 之前，你至少要會的五件事；缺哪個，就先補哪個。

agent 能幫你很多，但驗證與判斷是你的工作。以下五項是最低門檻，每項都附自我測驗。

1. 終端機與檔案路徑

最低要會自我測驗
在資料夾中開啟終端機、切換目錄、列出檔案不用滑鼠，進到練習專案資料夾並列出檔案
知道目前工作目錄在哪說出「為什麼要在專案根目錄啟動 agent」
cd D:/work/OrderDemo
dir            # PowerShell / cmd 列出檔案；Git Bash 可用 ls
git status

2. Git 基本功

最低要會指令
看目前狀態與差異git status、git diff、git diff --stat
開分支、提交git switch -c lab2-fix、git add -A、git commit -m "..."
丟掉不要的修改git restore 檔案（還原單一檔案）
暫存目前進度git stash、git stash pop

自我測驗：在新分支改一個檔案、看 diff、再完全還原，全程不經 agent。

git restore 會直接丟掉未提交的修改，無法復原。執行前先用 git diff 確認真的不要。

3. 讀 diff

agent 的每次修改你都要看 diff。最低要會：

  • 認得 +（新增）、-（刪除）、@@（位置）。
  • 先看 git diff --stat 了解動了哪些檔案，再逐檔看內容。
  • 特別留意刪除的行和條件判斷的改動。

4. 單元測試基本概念（xUnit）

[Fact]
public void Cancel_AlreadyCancelledOrder_Fails()
{
    // Arrange：準備資料
    var service = new OrderService(new InMemoryOrderRepository());

    // Act：執行被測行為
    var result = service.Cancel(orderId: 3, departmentId: 1);

    // Assert：驗證結果
    Assert.False(result.Success);
}
最低要會自我測驗
跑測試並看懂通過／失敗執行 dotnet test，說出結果的三個數字代表什麼
「先失敗再通過」的意義能解釋為什麼測試要先看到它失敗

5. HTTP、API 與前端基本概念

主題最低要會
HTTPGET 與 POST 的差別、狀態碼 200 / 400 / 404 / 500 的意思
MVCController 接請求、Service 處理邏輯、View 產生頁面
Vue 基本語法v-for、v-model、v-on:click、{{ }} 插值
前端呼叫 API看得懂 fetch 與 async/await

怎麼補

這些都可以請 agent 當老師教你（見把 agent 當老師），但要自己動手做過一次。每項花 30 分鐘到 1 小時即可，不需要精通。

自我檢核

  • 我能在新分支改檔案、看 diff、還原。
  • 我能跑 dotnet test 並看懂結果。
  • 我能說出一個 API 請求從前端到 Service 的路徑。
  • 我能看懂一段簡單的 Vue 模板。

常見任務食譜（.NET MVC＋Vue）

日常開發最常遇到的七種任務，各有一套可重複使用的做法與提示。

前面的章節教流程，這一區教具體的任務：遇到某種工作時，該怎麼和 agent 一起做。每份食譜都有：情境、步驟、提示範例、檢查清單與這個技術棧特有的陷阱。

本章範例以 ASP.NET Core MVC（.NET 8）＋ Vue 3，前後端在同一個 .NET 專案為基準。若你的專案是 .NET Framework 的 ASP.NET MVC 5，觀念與流程相同，但建置與測試指令（例如 MSBuild、vstest）、專案檔格式與設定檔不同，請在你的 CLAUDE.md 中寫清楚。

食譜一覽

每個食譜的共同骨架

1. 先唯讀：讓 agent 讀懂相關程式，說明現況 2. 要證據：重現問題／寫失敗的測試／列驗收條件 3. 小步改：只做這一件事，範圍明確 4. 驗證：跑測試、實際操作，貼出輸出 5. 審：看 diff，必要時交叉審查 6. 留下：commit、必要的文件或 CLAUDE.md 更新

技術棧特有的注意事項

面向注意
MVC 分層Controller 薄、Service 厚；不要讓 agent 把邏輯寫進 Controller 或 View
Razor 與 Vue@ 衝突、伺服器資料傳給前端的方式、防偽造權杖（見Vue 與 MVC）
資料庫migration 與正式資料由人決定（見EF 與 SQL）
測試Service 用單元測試、API 用整合測試、前端純函式用 Node 測試

省 Token 技巧

  • 貼堆疊與 log 時，只貼最後的例外與附近 20～30 行；用 !dotnet test 取輸出再裁剪。
  • 測試用 --filter 只跑相關的，驗證階段才跑全部。
  • 大型舊專案先請 agent 做「導覽筆記」存檔，之後直接讀。
  • 一個食譜一個對話；完成後 /clear。

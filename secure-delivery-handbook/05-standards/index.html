標準與法規

技術標準、管理體系與法規的整理：各自解決什麼問題、與軟體公司的關係、對應到手冊哪些頁面。

四類規範

類型代表性質頁面
應用安全標準OWASP Top 10、ASVS、API Security怎麼把網站與 API 做安全（技術面）OWASP
框架與指引NIST CSF、SSDF、SP 800 系列美國聯邦體系的框架，國際廣泛引用NIST
管理體系（可驗證）ISO/IEC 27001（CNS 27001）組織層級的資安管理制度，可取得第三方驗證ISO／CNS 27001
組態與控制基準CIS Controls、CIS Benchmarks優先順序明確的控制項與逐項設定基準CIS
法規與產業要求個資法、資通安全管理法、GDPR、PCI DSS具法律或合約強制力法規

依客戶類型選用（建議起點）

客戶類型建議採用說明
一般企業官網、會員網站OWASP Top 10＋ASVS L1／L2、CIS 基準、個資法以應用安全與基本合規為主
電商、金流上列＋PCI DSS（範圍依金流串接方式而定）盡量用第三方託管付款頁以縮小範圍
政府機關標案資通安全管理法與資通系統防護基準、常被要求 ISO 27001契約會載明資安要求，需對照委外條款
服務歐盟居民上列＋GDPR域外適用：不在歐盟也可能適用
金融、醫療等特定產業上列＋該產業主管機關規範本手冊尚未涵蓋產業專屬規範

檢查清單

把分散在各頁的檢查項目彙整成可勾選、可記錄、可列印的清單。

怎麼用

  1. 選擇專案（頁面頂端的工具列，可新增多個專案）。
  2. 依情境開啟對應清單，逐項勾選；進度會自動計算。
  3. 需要留存時按列印（另存 PDF），抬頭會帶上專案名稱與日期。
  4. 勾選狀態只存在你的瀏覽器，換瀏覽器或清除資料就會消失；重要紀錄請列印保存。

清單

內容來源與更新

  • 階段與技術領域的清單由 _build/build_checklists.py 從來源頁面自動彙整，來源頁是唯一維護處。
  • 新增或修改來源頁的檢查項目後，在專案根目錄執行 python _build/build_checklists.py 即可更新。
  • 定期維運、人員帳號、報告範本為本區塊自有內容。
勾選以項目文字為依據：來源頁與彙整頁的同一句項目會同步勾選；修改項目文字後，該項的舊勾選紀錄會失效。

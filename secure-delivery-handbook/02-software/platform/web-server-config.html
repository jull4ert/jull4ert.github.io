網頁伺服器設定

隱藏版本、強制 HTTPS 與加上安全標頭的設定範例。

原則

  • 停用目錄列表、隱藏版本資訊、移除預設頁面與範例。
  • 僅啟用 TLS 1.2／1.3，HTTP 一律轉 HTTPS（詳見 TLS 設定）。
  • 統一在伺服器或閘道加上安全標頭（詳見 安全標頭）。
  • 限制請求大小與逾時，降低慢速攻擊影響。

各技術實作

範例為最小示意，用來說明做法，套件 API 會隨版本調整，實作時請對照該版本的官方文件。上方篩選列可只顯示你用的技術。
server_tokens off;
ssl_protocols TLSv1.2 TLSv1.3;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
client_max_body_size 10m;
autoindex off;
<system.webServer>
  <security><requestFiltering removeServerHeader="true" /></security>
  <httpProtocol>
    <customHeaders>
      <remove name="X-Powered-By" />
      <add name="X-Content-Type-Options" value="nosniff" />
      <add name="Referrer-Policy" value="strict-origin-when-cross-origin" />
    </customHeaders>
  </httpProtocol>
</system.webServer>

TLS 協定與加密套件由 Windows Schannel 設定（登錄檔或 IIS Crypto 等工具），不在 web.config。

ServerSignature Off
Options -Indexes
SSLProtocol -all +TLSv1.2 +TLSv1.3
Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"

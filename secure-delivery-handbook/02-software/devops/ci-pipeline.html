CI 安全管線

把機敏資訊掃描、依賴／映像掃描與 SAST 放進每次提交的流程。

原則

  • PR 階段即執行掃描，嚴重項目阻擋合併（細節見 程式碼與依賴掃描）。
  • 管線權限預設唯讀，需要時才提升（如 GitHub Actions 的 permissions）。
  • 第三方 Action 固定到 commit SHA，避免標籤被改寫。
  • 不讓來自 fork 的 PR 取得密鑰。
  • 主幹建置時產生 SBOM 並存檔。

各技術實作

範例為最小示意，用來說明做法，套件 API 會隨版本調整，實作時請對照該版本的官方文件。上方篩選列可只顯示你用的技術。
name: security
on: [pull_request]
permissions:
  contents: read
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@<commit-sha>
        with: { fetch-depth: 0 }
      - name: Secret scan
        uses: gitleaks/gitleaks-action@<commit-sha>
      - name: Dependency / filesystem scan
        uses: aquasecurity/trivy-action@<commit-sha>
        with:
          scan-type: fs
          severity: CRITICAL,HIGH
          exit-code: '1'
include:
  - template: Security/SAST.gitlab-ci.yml
  - template: Security/Secret-Detection.gitlab-ci.yml
  - template: Jobs/Dependency-Scanning.gitlab-ci.yml
steps:
  - task: MicrosoftSecurityDevOps@1
    displayName: Microsoft Security DevOps

需先安裝 Microsoft Security DevOps 擴充套件；亦可於管線中直接執行 gitleaks、Trivy 等 CLI。

密碼儲存

資料庫外洩時，密碼雜湊的強度決定損害大小。

原則

  • 使用專為密碼設計的慢雜湊：首選 Argon2id，其次 scrypt、bcrypt，需要 FIPS 時用 PBKDF2。
  • 不要用 MD5、SHA-1、單次 SHA-256，也不要自行發明加密。
  • 鹽（salt）由函式庫自動產生；可加 pepper（存放於金鑰管理，不與資料庫同處）。
  • 支援「登入時自動升級雜湊」，參數調高後可平滑遷移。

參數參考

以下為 OWASP Password Storage Cheat Sheet 撰寫時的最低建議，數值會隨硬體演進更新，請以官方頁面當前內容為準。
演算法建議最低參數
Argon2id記憶體 19 MiB、迭代 2、平行度 1（或記憶體 46 MiB、迭代 1）
scryptN=2^17、r=8、p=1
bcryptwork factor ≥ 10（注意有 72 位元組輸入上限）
PBKDF2-HMAC-SHA256600,000 次迭代

各技術實作

範例為最小示意，用來說明做法，套件 API 會隨版本調整，實作時請對照該版本的官方文件。上方篩選列可只顯示你用的技術。

ASP.NET Core Identity 內建 PasswordHasher<T>（PBKDF2）；預設迭代次數可能低於上表建議，可用 PasswordHasherOptions.IterationCount 調整，或改用 Argon2 套件。

var hasher = new PasswordHasher<AppUser>();
var hash   = hasher.HashPassword(user, password);
var result = hasher.VerifyHashedPassword(user, hash, password);
// PasswordVerificationResult: Success / SuccessRehashNeeded / Failed
import argon2 from 'argon2';
const hash = await argon2.hash(password);        // 預設 argon2id
const ok   = await argon2.verify(hash, password);

Argon2 實作需要 BouncyCastle 相依。

PasswordEncoder encoder = Argon2PasswordEncoder.defaultsForSpringSecurity_v5_8();
String hash = encoder.encode(rawPassword);
boolean ok  = encoder.matches(rawPassword, hash);
from argon2 import PasswordHasher
ph = PasswordHasher()
h = ph.hash(password)
ph.verify(h, password)   # 失敗會丟出 VerifyMismatchError
# ph.check_needs_rehash(h) 可判斷是否需升級參數
$hash = password_hash($password, PASSWORD_ARGON2ID);  // 或 PASSWORD_DEFAULT（目前為 bcrypt）
if (password_verify($password, $hash)) { /* 通過 */ }
// password_needs_rehash() 判斷是否需升級

網路分段與防火牆

預設拒絕的規則範例，涵蓋主機防火牆與雲端安全群組。

典型分層

公網 ─(443)→ [WAF/負載平衡] ─→ DMZ／Web 層 ─(應用埠)→ 應用層 ─(資料庫埠)→ 資料庫層
                                   管理網（跳板機、VPN）─(僅管理埠)→ 各層
資料庫層：不允許直接來自公網或 Web 層以外的來源

規則原則

  • 資料庫只接受應用層的來源（以安全群組或子網路限制）。
  • 出站也要管控：限制伺服器可連的目的地，能擋掉許多資料外傳與後門回連。
  • 每條規則有用途與負責人，定期清理過期規則。
  • 變更走變更管理並留存紀錄。

各技術實作

範例為最小示意，用來說明做法；指令與選項會隨版本、廠商調整，實作前請對照官方文件，並先在測試環境驗證。上方篩選列可只顯示你用的技術。
table inet filter {
  chain input {
    type filter hook input priority 0; policy drop;
    ct state established,related accept
    iif lo accept
    tcp dport 22 ip saddr 10.0.0.0/24 accept     # 僅管理網段可 SSH
    tcp dport { 80, 443 } accept
  }
}
Set-NetFirewallProfile -Profile Domain,Public,Private -DefaultInboundAction Block
New-NetFirewallRule -DisplayName "Allow HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow
# 資料庫只接受應用層安全群組的來源
aws ec2 authorize-security-group-ingress --group-id <sg-db> \
  --protocol tcp --port 5432 --source-group <sg-app>
az network nsg rule create --resource-group <rg> --nsg-name <nsg> \
  --name allow-https --priority 100 --direction Inbound --access Allow \
  --protocol Tcp --destination-port-ranges 443
gcloud compute firewall-rules create allow-https \
  --direction INGRESS --allow tcp:443 --target-tags web

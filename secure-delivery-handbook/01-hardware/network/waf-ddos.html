WAF 與 DDoS 防護

在邊界吸收與過濾惡意流量，作為應用安全的補充防線。

原則

  • WAF 是補充，不能取代修補與安全編碼；常用於暫時緩解已知漏洞（虛擬修補）。
  • 先以偵測／計數模式觀察誤報，再切到阻擋。
  • 託管規則集（如 OWASP Core Rule Set 衍生）加上針對自身應用的自訂規則與速率限制。
  • DDoS：優先使用 CDN／雲端商的流量清洗與任播；源站只接受來自 CDN／WAF 的流量，並隱藏真實 IP。
  • 有容量規劃與緊急聯絡流程（含 ISP、CDN）。

各技術實作

範例為最小示意，用來說明做法；指令與選項會隨版本、廠商調整，實作前請對照官方文件，並先在測試環境驗證。上方篩選列可只顯示你用的技術。

AWS WAF：套用託管規則群組（如 Core rule set）並加入速率型規則；AWS Shield Standard 對所有客戶自動提供基礎 DDoS 防護，進階防護另有 Shield Advanced。

Azure Front Door 或 Application Gateway 的 WAF 可啟用預設規則集（含 OWASP 規則），並設定偵測／防止模式與速率限制；DDoS 防護另有網路層級方案。

Google Cloud Armor 搭配外部負載平衡器提供 WAF 規則、速率限制與 DDoS 防護，可先以預覽模式評估規則影響。

檢查清單

指令與設定為最小示意，會隨版本與廠商而異，請在測試環境驗證並對照官方文件後再用於正式環境。

VPN 與遠端存取

讓員工與廠商安全連入內部資源，並避免 VPN 成為單一弱點。

原則

  • VPN 帳號個人化並啟用 MFA；離職與異動即時撤銷。
  • 最小存取：連上 VPN 不等於能到處走，依角色限制可達的網段與服務。
  • VPN 閘道本身要及時修補（常是被攻擊的目標）；公開的管理介面要限制。
  • 裝置健康檢查（是否加密、有更新）作為連入條件更佳。
  • 考慮零信任存取（ZTNA）取代全網段 VPN。

選擇

方式特點
WireGuard精簡、效能佳、設定簡單；金鑰管理需自行規劃
IPsec／IKEv2廣泛支援，與商用設備整合佳
ZTNA／反向代理依應用授權、較細緻，適合大量第三方存取

各技術實作

範例為最小示意，用來說明做法；指令與選項會隨版本、廠商調整，實作前請對照官方文件，並先在測試環境驗證。上方篩選列可只顯示你用的技術。
# /etc/wireguard/wg0.conf（伺服器端示意）
[Interface]
PrivateKey = <server-private-key>
Address = 10.8.0.1/24
ListenPort = 51820

[Peer]
PublicKey = <client-public-key>
AllowedIPs = 10.8.0.2/32      # 限制此對等端只能使用這個位址

可使用 Windows Server 的遠端存取／Always On VPN，或第三方方案；重點是 MFA、憑證驗證與依角色限制的網段，而非單一指令。

檢查清單

指令與設定為最小示意，會隨版本與廠商而異，請在測試環境驗證並對照官方文件後再用於正式環境。

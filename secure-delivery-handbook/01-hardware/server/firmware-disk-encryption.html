韌體、可信開機與磁碟加密

保護開機鏈與靜態資料：設備遺失、被拆硬碟或報廢時仍安全。

原則

  • 啟用 UEFI Secure Boot 與 TPM，BIOS／UEFI 設定密碼並限制開機順序。
  • 韌體更新：BIOS、BMC、網卡、RAID 韌體也要修補並追蹤公告。
  • 全碟加密：伺服器與筆電都啟用；金鑰與復原金鑰妥善保管（不與資料同處）。
  • BMC（如 iDRAC、iLO、IPMI）：改預設密碼、停用不用的功能、僅放管理網段。

各技術實作

範例為最小示意，用來說明做法；指令與選項會隨版本、廠商調整，實作前請對照官方文件，並先在測試環境驗證。上方篩選列可只顯示你用的技術。
Get-Tpm
Confirm-SecureBootUEFI
Get-BitLockerVolume
Enable-BitLocker -MountPoint "D:" -EncryptionMethod XtsAes256 -RecoveryPasswordProtector
# 復原金鑰請備份到安全位置（如 AD／Entra ID 或密鑰保管系統）
mokutil --sb-state                        # 檢視 Secure Boot 狀態
# LUKS 會清除資料：僅用於新磁碟，並先確認裝置名稱
sudo cryptsetup luksFormat /dev/sdX
sudo cryptsetup open /dev/sdX data
sudo mkfs.ext4 /dev/mapper/data

檢查清單

指令與設定為最小示意，會隨版本與廠商而異，請在測試環境驗證並對照官方文件後再用於正式環境。

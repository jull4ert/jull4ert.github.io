遠端管理與跳板機

管理通道是高價值目標：不對公網、強驗證、全程可追溯。

原則

  • SSH、RDP、資料庫管理埠不直接對公網開放；經由 VPN 或跳板機（bastion）。
  • 強驗證：SSH 用金鑰（停用密碼）、管理者加 MFA。
  • 個人帳號各自登入，不共用；特權操作需留存紀錄（連線與指令稽核）。
  • 連線來源限制與逾時；管理工作站與一般辦公分離為佳。
  • RDP 啟用網路層級驗證（NLA）並設定帳號鎖定原則。

各技術實作

範例為最小示意，用來說明做法；指令與選項會隨版本、廠商調整，實作前請對照官方文件，並先在測試環境驗證。上方篩選列可只顯示你用的技術。
ssh-keygen -t ed25519 -C "name@host"

# ~/.ssh/config：經跳板機連線
Host bastion
  HostName bastion.example.com
  User ops
Host app-*
  ProxyJump bastion

RDP 不要直接對外：僅開放給 VPN 或跳板機來源，並啟用 NLA 與帳號鎖定。檢視防火牆規則：

Get-NetFirewallRule -DisplayName "Remote Desktop*" |
  Select-Object DisplayName, Enabled, Profile, Direction

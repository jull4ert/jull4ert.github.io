作業系統加固

縮小攻擊面：移除不需要的、鎖緊必要的、持續更新。

原則

  • 以基準為準（CIS Benchmark、各廠商安全基準），差異需有書面理由。
  • 停用不需要的服務、協定與帳號；只開放必要的入站埠。
  • 管理者帳號分離、本機管理員密碼唯一且輪替。
  • 啟用稽核日誌並送往集中儲存。
  • 自動化：以組態管理工具或映像管理維持一致，避免手動改機。

各技術實作

範例為最小示意，用來說明做法；指令與選項會隨版本、廠商調整，實作前請對照官方文件，並先在測試環境驗證。上方篩選列可只顯示你用的技術。
# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
MaxAuthTries 3
AllowUsers deploy

sudo sshd -t && sudo systemctl reload ssh   # 先檢查語法再套用（服務名依發行版為 ssh 或 sshd）
ss -tulpn                                   # 檢視對外監聽的服務
sudo apt install unattended-upgrades        # Debian／Ubuntu 自動安全更新
sudo lynis audit system                     # 以 Lynis 做加固檢查
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True
Set-SmbServerConfiguration -EnableSMB1Protocol $false -Force
Get-NetTCPConnection -State Listen | Select-Object LocalAddress,LocalPort,OwningProcess
Get-WindowsFeature | Where-Object Installed   # 檢視已安裝角色，移除不需要的

可搭配 Microsoft Security Compliance Toolkit 的安全基準，與 Windows LAPS（本機管理員密碼唯一且輪替）。

檢查清單

指令與設定為最小示意，會隨版本與廠商而異，請在測試環境驗證並對照官方文件後再用於正式環境。

帳號遭盜用

使用者或管理者帳號被他人登入或操作。

通用流程見 應變流程。本頁是這個情境的補充重點。

徵兆

  • 異常的登入地點、時間或裝置
  • 非本人操作的訂單、設定或權限變更
  • 大量失敗登入後突然成功（憑證填充）
  • 客戶回報被盜、被改信箱或電話

最先做

  1. 確認是單一帳號還是大量；若是管理者帳號，視為 P1／P2
  2. 保存登入與操作日誌
  3. 停用或鎖定受影響帳號

遏止

  • 強制登出所有工作階段、撤銷權杖與 API 金鑰
  • 要求改密碼並重新綁定 MFA
  • 檢查是否有被新增的備用信箱、轉寄規則、OAuth 授權、API 金鑰

根除

  • 查明密碼是如何被取得（外洩資料庫重用、釣魚、惡意軟體、弱密碼）
  • 若屬大量憑證填充，啟用速率限制、CAPTCHA、洩漏密碼檢查與 MFA
  • 檢查是否有權限提升或資料被匯出

復原

  • 還原被未授權變更的資料
  • 通知受影響使用者並說明如何自保
  • 對管理者帳號強制 MFA

通報判斷

  • 若帳號被用來存取個資，依 資料外洩 判斷
  • 涉及金流或交易時通知金流與客戶

常見錯誤

  • 只重設密碼卻未撤銷既有工作階段與權杖
  • 沒有檢查帳號被加上的後門設定

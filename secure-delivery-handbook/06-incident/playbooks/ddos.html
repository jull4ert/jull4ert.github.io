DDoS

大量流量或請求耗盡頻寬、連線或運算資源，使服務變慢或無法使用。

通用流程見 應變流程。本頁是這個情境的補充重點。

徵兆

  • 流量或請求數異常飆升、CPU／連線數滿載
  • 特定頁面（登入、搜尋、報表）被集中打
  • 來源 IP 分散或有固定特徵（User-Agent、路徑）
  • 勒索型 DDoS：收到威脅要打你，除非付款

最先做

  1. 確認是攻擊還是正常流量暴增（活動、爬蟲）
  2. 聯絡 CDN／雲端／主機商，啟用其防護或升級方案
  3. 記錄開始時間、流量曲線、攻擊特徵

遏止

  • 啟用 CDN 與 WAF 的挑戰與速率限制，封鎖明顯惡意特徵
  • 針對被打的昂貴端點設限流或暫時關閉
  • 必要時調整 DNS 指向防護服務（需預先設定）
  • 擴容只能延緩，要同時處理來源

根除

  • 攻擊結束後檢視弱點：哪個端點太昂貴、原站 IP 是否被暴露
  • 限制原站只接受 CDN／防護服務的來源

復原

  • 流量恢復後逐步放寬規則並觀察
  • 更新防護策略與預先備好的應變設定

通報判斷

  • 勒索型 DDoS：不付款，通知客戶並保存勒索訊息
  • 大規模或長時間攻擊時，通知客戶與可能受影響的第三方

常見錯誤

  • 到事故當下才找防護廠商開通
  • 把原站 IP 暴露在 DNS 紀錄或郵件標頭

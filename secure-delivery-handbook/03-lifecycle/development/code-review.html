程式碼審查（資安面向）

人工審查補足自動化工具抓不到的邏輯與授權問題。

審查重點

何時需要資安人員參與

  • 認證、授權、Session 機制變更。
  • 金流、個資處理、加密相關程式碼。
  • 新增對外 API 或第三方整合。
  • 架構調整，例如新增服務或資料流。

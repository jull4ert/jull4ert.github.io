網站強化設定

不改業務程式碼，僅靠伺服器與標頭設定就能提升的防護。

這類設定成本低、效益高，也最容易被客戶的外部掃描（例如 SSL Labs、securityheaders.com）直接看到，建議每個專案都有統一基準。

快速自我檢測

  • SSL Labs Server Test：TLS 設定評分。
  • Security Headers：HTTP 安全標頭評分。
  • Mozilla HTTP Observatory：綜合檢查。

這些是公開的第三方線上服務，只會掃描你輸入的公開網址，內網或預備環境請改用本機工具。

TLS／HTTPS 設定

傳輸加密的基準：協定版本、憑證、HSTS。

基準

項目建議
協定版本啟用 TLS 1.2 與 1.3；停用 SSLv3、TLS 1.0、1.1
加密套件使用具前向保密（ECDHE）的現代套件；請以 Mozilla 設定產生器的 Modern／Intermediate 為準
憑證由受信任 CA 簽發、網域名稱相符、未過期；設定到期提醒與自動續期
HTTP 轉址所有 HTTP 請求 301 轉到 HTTPS
HSTS啟用 Strict-Transport-Security，先小 max-age 驗證再拉長
內部連線前後端、後端到資料庫也建議加密，不只對外

HSTS 範例

Strict-Transport-Security: max-age=31536000; includeSubDomains
preload 與 includeSubDomains 一旦推行很難回頭：所有子網域都必須支援 HTTPS。上線初期建議先用短 max-age 觀察。

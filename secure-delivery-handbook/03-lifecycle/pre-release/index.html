上線前檢查

網站（前後端）放行前必做的資安檢查，以及放行判斷（Go/No-Go）。

檢查流程

程式碼凍結
   ├─ 1. 程式碼與依賴掃描  （SAST／依賴／機敏資訊）  → 自動化，每次 commit 可跑
   ├─ 2. 部署到「預備環境」（與正式環境設定一致）
   ├─ 3. 網站強化設定檢查  （TLS／標頭／Cookie）
   ├─ 4. 弱點掃描          （DAST、主機/容器）
   ├─ 5. 滲透測試          （依風險分級決定是否必要）
   └─ 6. 驗收與 Go/No-Go   （風險簽核）

項目抓什麼誰做頻率

弱點掃描執行中服務的已知弱點與錯誤設定資安／維運上線前＋每月

子主題

原則：嚴重／高風險弱點未修補或未取得書面風險接受，不得上線。「嚴重度」定義見 弱點掃描 › 嚴重度與處理時限。

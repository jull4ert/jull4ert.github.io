機敏資訊外洩掃描

金鑰、密碼、token、連線字串不應出現在原始碼與 git 歷史中。

常見外洩位置

  • 程式碼與設定檔（appsettings.json、.env、前端打包後的 JS）。
  • git 歷史紀錄：即使最新版已刪除，舊 commit 仍可取得。
  • CI 日誌、Docker image 層、Issue／聊天紀錄。

防線（由前到後）

階段作法
預防機敏設定改放環境變數或密鑰管理服務（如 Vault、雲端 Key Vault）；.gitignore 排除 .env
提交前pre-commit hook 掃描（如 gitleaks）
CIPR 與主幹掃描，含歷史
遠端啟用託管平台的 secret scanning／push protection

一旦外洩

先作廢並輪替金鑰，再清理歷史。只刪除程式碼或改寫歷史並不能讓已外洩的金鑰恢復安全。
  1. 立即撤銷／輪替該金鑰與相關憑證。
  2. 檢查日誌，確認有無被濫用。
  3. 必要時清理 git 歷史，並通知客戶（依合約與法規時限）。
  4. 補上預防措施，避免再次發生。

原始碼靜態分析（SAST）

在不執行程式的情況下，掃描原始碼中的不安全寫法。

能抓與不能抓

較能抓到較難抓到
SQL／命令注入的危險寫法、寫死的密碼、弱雜湊演算法、不安全的反序列化授權邏輯缺陷、商業邏輯錯誤、僅在執行期與設定組合下才出現的問題

工具範例

工具特點
Semgrep多語言、規則易寫、可自訂團隊規則
CodeQLGitHub 原生，以查詢語言做資料流分析
SonarQube程式品質與安全合併呈現，可設品質閘門

依你的技術棧選擇即可（例如 .NET 專案可用 CodeQL 或 SonarQube）。

落地建議

  • 先對新增／修改的程式碼設阻擋，舊債另外排程，避免一開始就被數百筆告警淹沒。
  • 每筆誤報要標註原因，避免同一問題反覆審查。
  • 規則集以 OWASP Top 10 對應為起點，再依專案補強。

程式碼與依賴掃描

不需執行系統，直接檢查原始碼與套件的自動化掃描，適合放進 CI。

三類掃描看不同層面，缺一不可：自己寫的程式碼（SAST）、別人寫的套件（依賴）、不該提交的祕密（機敏資訊）。

CI 整合建議

pull request
  ├─ secrets scan      失敗即阻擋
  ├─ dependency scan   嚴重/高風險阻擋
  └─ SAST              新增的高風險阻擋，其餘列入報告
merge 到主幹 → 產生 SBOM 並存檔

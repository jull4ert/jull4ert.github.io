第三方依賴與 SBOM

網站大部分程式碼其實來自套件。檢查它們有無已知漏洞，並留存清單。

要做什麼

  1. 盤點：列出直接與間接依賴（前端 npm、後端 NuGet／Maven／pip 等），鎖定版本（lock file）。
  2. 比對漏洞資料庫：以工具比對 CVE／GHSA 等資料。
  3. 評估可利用性：弱點的函式是否真的被呼叫？是否在正式環境套件中（而非僅開發用）？
  4. 升級或緩解：升版、替換套件，或以設定／WAF 暫時緩解。
  5. 產出 SBOM：隨版本存檔，日後出現新漏洞時能快速回答「我們有沒有用到」。

工具範例

工具用途
OWASP Dependency-Check多語言依賴漏洞掃描
OSV-Scanner以 OSV 資料庫比對
Dependabot／Renovate自動提出升版 PR
npm audit、dotnet list package --vulnerable各生態系內建指令
CycloneDX／SPDXSBOM 格式

前端特別注意

  • CDN 引入的第三方腳本，加上 Subresource Integrity（integrity 屬性）並固定版本。
  • 避免引入無人維護或下載量極低的套件（供應鏈攻擊與 typosquatting 風險）。

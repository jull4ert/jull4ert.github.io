快速交付與原型

從想法到能運作的東西：分階段交付，先做一條完整的路，並用 .NET MVC＋Vue 實作

FDE 的特色是「做得出來」。這一區談怎麼快，又不失控：用階段與出口條件管理風險，用垂直切片取得早期回饋，用程式結構讓原型可以長成正式系統。

技術範例以 ASP.NET Core MVC（.NET 8）＋ Vue 3，前後端同一個 .NET 專案為基準，並以練習專案 sample/TicketDesk 為例。若你的專案是 .NET Framework 的 ASP.NET MVC 5，觀念相同，但建置與測試指令、專案檔格式不同。

建議順序

  1. POC、試辦、正式上線：三個階段與各自的出口條件
  2. 垂直切片：先做一條從頭到尾的完整路徑
  3. 在 ASP.NET Core 呼叫模型：介面、逾時、機密、解析
  4. 串流到 Vue：Server-Sent Events 與 fetch 讀取
  5. 把提示當程式管理：版本、結構化、與資料分離
  6. 成本與延遲：估算、量測與控制

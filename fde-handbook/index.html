FDE 技能手冊

Forward Deployed Engineer 的技能養成：聚焦 AI／agent 導入，從看懂客戶的問題，到做出來、接進現有系統、評估品質、讓人真的用起來。範例以 .NET MVC＋Vue 為主，並涵蓋非程式領域與觸類旁通。

定位與範圍

  • 定位：技能養成手冊。每個技能頁都回答：是什麼、為什麼 FDE 需要、怎麼做、業界情境、常見錯誤、非程式版、怎麼練、可觀察的證據、觸類旁通。
  • 焦點：AI／agent 導入。FDE 的價值不在模型本身，而在把 agent 落地到客戶真實的資料、流程與人。
  • 技術基準：ASP.NET Core MVC（.NET 8）＋ Vue 3，前後端同一個 .NET 專案；練習專案 sample/TicketDesk。
  • 非程式領域：獨立成一區，並在各技能頁附「非程式領域怎麼用」。
  • 觸類旁通：一區專門談相鄰職務、可遷移的原則與相鄰技術，並在各頁附「觸類旁通」。
  • 情境：頁面中的業界情境皆為虛構組合，數字與名稱為示意；有來源的事實會附出處，未查證的說法會明說。
  • 與 AI Agent 開發手冊 的分工：那本教「怎麼用 agent 做事」；這本教「怎麼把 agent 帶進別人的組織並做到有成果」。
  • 範圍外：模型訓練、純銷售與商務談判、各雲端平台的完整操作手冊、法律意見。
請先讀實測驗證紀錄：它說明哪些內容實際執行過、哪些只是讀過來源、哪些沒有驗證（例如真實模型的呼叫、瀏覽器中的畫面行為、法規的現行條文）。

分類邏輯：一個專案的生命週期

FDE 的工作依時間順序展開，所以手冊按「專案進行的先後」分區，讀者可以對照自己現在卡在哪個階段。

看懂客戶 → 設計方案 → 做出來 → 接進系統 → 證明有效 → 取得信任 → 讓人用起來 → 複製擴散 02 03 04 05 06 07 08 10 （貫穿全程：09 溝通；基礎：00、01；延伸：11、12、13、14）

由淺到深的學習階段

  • Lv1 能協助：懂角色與流程，能在資深 FDE 帶領下做訪談紀錄、整理需求、做簡單原型。（00、01、02 入門、04 入門、Lab 0 到 2）
  • Lv2 能獨立做一個小案：能獨立完成「問題定義 → 方案 → 原型 → 評估」。（02 到 06、Lab 3 到 4）
  • Lv3 能把案子帶到上線：能處理整合、資安審查、使用者採用與交接。（05、07、08、09、Lab 5 到 8）
  • Lv4 能放大影響：能把多個客戶的經驗抽象成產品與方法，並帶領他人。（10、11、14）

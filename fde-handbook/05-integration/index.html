整合企業系統

把 AI 接進客戶的舊系統、資料、身分與網路：這是 AI 專案最常卡住的地方

模型能力再強，若接不進客戶的系統，就只是一個展示。整合是 FDE 最能展現價值的地方，也是最能被「現實」打敗的地方：舊系統、髒資料、權限、防火牆。

技術範例以 ASP.NET Core MVC（.NET 8）＋ Vue 3，前後端同一個 .NET 專案為基準，並以練習專案 sample/TicketDesk 為例。若你的專案是 .NET Framework 的 ASP.NET MVC 5，觀念相同，但建置與測試指令、專案檔格式不同。

建議順序

  1. 舊系統與資料來源：唯讀優先、找出真正的資料來源
  2. 資料品質：盤點、剖析與清理，含民國年等台灣常見問題
  3. 工具與 MCP：把客戶系統的能力安全地交給模型
  4. 身分與權限：以使用者身分操作，最小權限
  5. 內網、防火牆與資料落地：客戶環境的現實限制
  6. 整合設計模式：冪等、重試、影子模式、降級
